# Linux System Information Script

A simple Bash script that display basic system information using common Linux commands.
## Features

- Displays current username
- Shows date and Time
- Displays operation system information
- Shows current working directory
- Displays memory information

## Requirements
- Bash
- Linux or Git Bash on Windows

## How to Run
- '''bash
  Chmod +x system_info.sh
  ./system_info.sh
  '''
